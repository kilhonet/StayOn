## 概述

你大概遇到过这种情况:演示文稿开着、长时间下载跑着,或者正在读文档,几分钟后屏幕就黑了,电脑进入睡眠。而公司的电脑往往根本不允许更改电源设置。

StayOn 会在桌面角落放一只像素风的小猫。**点击睡着的小猫,它就会醒来**;小猫醒着的时候,屏幕不会关闭,电脑也不会进入睡眠。再点一下,小猫重新入睡,一切恢复原样。

完全不改动 Windows 的电源和睡眠设置。只在程序运行期间生效,退出或重启后不留任何痕迹。只有一个文件,不到 100 KB。

## 主要功能

- **一键开关** — 点击小猫即可开启或关闭防睡眠。右键菜单也可以。
- **防止关屏、睡眠和锁定** — 屏幕保护、关闭屏幕、睡眠模式、自动锁定都不会触发。还能防止 Teams 等即时通讯软件显示"离开"状态。
- **不改动 Windows 设置** — 不修改电源选项和组策略。也不需要管理员权限。
- **小猫随处安放** — 拖到想要的位置即可,位置会被记住。它不会跑出屏幕。
- **显示大小 100 % · 200 % · 400 %** — 按显示器大小选择小猫尺寸。在高分辨率(HiDPI)屏幕上同样清晰。
- **开机时运行** — 随 Windows 启动一起出现(安装版)。
- **轻巧简单** — 用 C 重写,可执行文件 83 KB,没有安装向导和设置窗口。始终置顶,但不会出现在任务栏或 Alt+Tab 列表中。
- **7 种语言** — 韩语、英语、日语、中文、俄语、意大利语、法语。跟随 Windows 显示语言。

## 使用方法

### 基本流程

1. 运行 StayOn。屏幕右下角(任务栏上方)出现一只**睡着的小猫**。
2. **点击**小猫。它伸个懒腰醒来,从此屏幕不会关闭、电脑不会睡眠。
3. 做你的事。小猫醒着的时候会一直留在屏幕上。
4. 做完后**再点一下**小猫。它重新入睡,睡眠设置恢复正常。

程序启动时小猫**总是处于睡着状态**。即使昨天让它醒着就退出了,下次启动也不会自动开启 — 这样就不会出现你并不想让屏幕常亮、它却亮着的情况。

### 界面构成

没有窗口和设置界面,只有小猫和它的**右键菜单**。

| 菜单 | 作用 |
|---|---|
| **运行** / **停止** | 开启/关闭防睡眠 — 和点击小猫一样 |
| **显示大小** › 100% · 200% · 400% | 小猫尺寸。默认 200% |
| **开机时运行**(勾选) | 随 Windows 启动自动运行(安装版) |
| **作者:吴吉浩** | 打开官网 |
| **退出** | 结束程序 — 防睡眠也一起关闭 |

- **睡着的小猫** = 防睡眠关闭,**醒着的小猫** = 防睡眠开启。不需要额外的状态指示,看小猫就知道。
- **拖动移动** — 按住小猫拖动即可移动。轻微移动视为点击。

### 这种情况怎么办

**演示或会议时不让屏幕关闭**
打开演示文稿前先点一下小猫把它叫醒。结束后再点一下让它睡觉。在投影仪或会议室电脑上也不用碰电源设置。

**挂着长时间下载或任务离开座位**
让小猫醒着,离开时电脑也不会睡眠,任务会继续进行。回来后让小猫睡觉即可。这与关闭电脑本身无关,任务完成后自行关机就好。

**Teams、Slack 老是变成"离开"状态**
只读文档或只听会议、不动鼠标时,通讯软件会把你标记为离开。让小猫醒着就不会变成离开状态。

**公司电脑无法更改电源设置**
StayOn 不改动 Windows 设置,也不使用管理员权限。即使是组策略固定了关屏时间的电脑,小猫醒着期间屏幕也会保持开启。

**小猫碍事**
- **拖**到想要的位置。位置会被记住。
- 右键 → **显示大小** → **100%**,几乎不引人注意。
- 小猫无法被推出屏幕,只会停在显示器边缘。

**小猫太小(4K 显示器等)**
右键 → **显示大小** → **400%**。它会再乘以 Windows 的缩放设置,所以在任何分辨率下都清晰。

**每次开机都让小猫出现**
在安装版中右键 → 勾选**开机时运行**。从下次开机起,登录后小猫会以睡着状态出现。免安装版中该项被锁定,请使用安装版。

**看不到小猫**
- 如果已经在运行,再次启动不会有任何反应(一次只有一只)。检查屏幕角落和其他显示器。
- 如果显示器配置变了、保存的位置跑到屏幕外,它会自动回到默认位置(主显示器右下角)。

**完全退出 StayOn**
右键 → **退出**。如果小猫醒着,防睡眠也会一起关闭。如果只是让小猫睡觉,程序仍在运行,下次可以立即再叫醒它。

**想确认防睡眠是否生效**
小猫醒着就在生效。想要确定的话,等到 Windows 设置 → 系统 → 电源中的关屏时间过后,看屏幕是否仍然亮着。

**想在另一台电脑上用同样的位置和大小**
设置保存在用户账户中,升级后也会保留。在新电脑上把小猫移动一次、选好大小,之后就会记住。

## 设置

没有设置窗口,在右键菜单中修改,修改后立即保存。

| 项目 | 默认值 |
|---|---|
| 显示大小 | 200% |
| 小猫位置 | 主显示器右下角(任务栏上方) |
| 开机时运行 | 关 |
| 防睡眠状态 | 不保存 — 总是以睡着状态启动 |

界面语言跟随 Windows 显示语言(韩语、英语、日语、中文、俄语、意大利语、法语,其他为英语)。
