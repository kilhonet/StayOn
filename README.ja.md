## 概要

プレゼン資料を表示したまま、長いダウンロードを走らせたまま、あるいは文書を読んでいる最中に、数分で画面が消えてパソコンがスリープしてしまった経験はありませんか。会社の PC では電源設定を変えられないことも多いはずです。

StayOn はデスクトップの隅にピクセルアートの猫を 1 匹置きます。**眠っている猫をクリックすると目を覚まし**、猫が起きている間は画面が消えることも、パソコンがスリープに入ることもありません。もう一度クリックすると猫は眠り、すべてが元どおりになります。

Windows の電源・スリープ設定には一切触れません。プログラムが動いている間だけ効果があり、終了や再起動をすれば何の痕跡も残りません。ファイル 1 つ、100 KB 未満です。

## 主な機能

- **ワンクリック** — 猫をクリックしてスリープ防止をオン/オフ。右クリックメニューからも操作できます。
- **画面オフ・スリープ・ロックを防止** — スクリーンセーバー、画面オフ、スリープ、自動ロックが働きません。Teams などメッセンジャーの「退席中」表示も防ぎます。
- **Windows 設定を変更しない** — 電源オプションもグループポリシーも変えません。管理者権限も不要です。
- **どこにでも置ける猫** — ドラッグで好きな場所に置くと位置を記憶します。画面の外には出ません。
- **表示サイズ 100 % · 200 % · 400 %** — モニターに合わせて猫の大きさを選べます。高解像度(HiDPI)画面でも鮮明です。
- **起動時に実行** — Windows の起動と同時に猫が現れます(インストーラー版)。
- **軽くてシンプル** — C で書き直し、実行ファイル 83 KB、セットアップや設定画面なし。常に最前面にいますが、タスクバーや Alt+Tab の一覧には出ません。
- **7 言語** — 韓国語・英語・日本語・中国語・ロシア語・イタリア語・フランス語。Windows の表示言語に従います。

## 使い方

### 基本の流れ

1. StayOn を起動します。画面右下(タスクバーの上)に**眠っている猫**が現れます。
2. 猫を**クリック**します。猫が伸びをして目を覚まし、これ以降は画面が消えたりパソコンがスリープしたりしません。
3. 作業をします。猫は起きている間、画面上にそのままいます。
4. 終わったら猫を**もう一度クリック**します。猫は再び眠り、スリープ設定は普段どおりに戻ります。

プログラムを起動すると猫は**必ず眠った状態**で始まります。昨日起こしたまま終了しても、次回起動時に勝手にオンにはなりません — 画面を点けておくつもりがないのに点いたまま、ということが起きないようにするためです。

### 画面構成

ウィンドウや設定画面はなく、猫と**右クリックメニュー**がすべてです。

| メニュー | 内容 |
|---|---|
| **実行する** / **停止する** | スリープ防止のオン/オフ — 猫をクリックするのと同じです |
| **表示サイズ** › 100% · 200% · 400% | 猫の大きさ。既定は 200% |
| **起動時に実行**(チェック) | Windows 起動時に自動実行(インストーラー版) |
| **作成者: オ・ギルホ** | ホームページを開く |
| **終了する** | プログラムを終了 — スリープ防止も一緒にオフになります |

- **眠っている猫** = スリープ防止オフ、**起きている猫** = スリープ防止オン。別の状態表示がなくても猫を見れば分かります。
- **ドラッグで移動** — 猫を押したままドラッグすると移動します。わずかな動きはクリックとみなします。

### こんなときは

**プレゼンや会議中に画面が消えないようにしたい**
資料を表示する前に猫を 1 回クリックして起こしておきましょう。終わったらもう一度クリックして寝かせます。プロジェクターや会議室の PC でも電源設定を触る必要はありません。

**長いダウンロードや処理を走らせたまま席を離れる**
猫を起こしておけば、席を離れてもパソコンがスリープせず処理が続きます。戻ったら猫を寝かせるだけです。パソコン自体の電源を切ることとは無関係なので、処理が終わったら自分でシャットダウンしてください。

**Teams・Slack がすぐ「退席中」になる**
文書を読んだり会議を聞いたりするだけでマウスを動かさないと、メッセンジャーは退席中と表示します。猫を起こしておけば退席中にはなりません。

**会社の PC で電源設定を変えられない**
StayOn は Windows の設定を変えず、管理者権限も使いません。グループポリシーで画面オフの時間が固定された PC でも、猫が起きている間は画面が維持されます。

**猫が作業の邪魔になる**
- 好きな場所へ**ドラッグ**してください。位置は記憶されます。
- 右クリック → **表示サイズ** → **100%** にすればほとんど目立ちません。
- 猫は画面の外へ押し出せません。モニターの端に当たるところまでしか動きません。

**猫が小さすぎる(4K モニターなど)**
右クリック → **表示サイズ** → **400%**。Windows の拡大率にさらに掛け合わせるので、どの解像度でも鮮明です。

**パソコンを起動するたびに猫を出したい**
インストーラー版で右クリック → **起動時に実行**にチェックを入れます。次回起動から、ログオンすると猫が眠った状態で現れます。ポータブル版ではこの項目がロックされているので、インストーラー版を使ってください。

**猫が見当たらない**
- すでに実行中なら、2 回目に起動しても何も起きません(一度に 1 匹だけです)。画面の隅や他のモニターを確認してください。
- モニター構成が変わって保存位置が画面外になった場合は、自動的に既定位置(メインモニターの右下)に戻ります。

**StayOn を完全に終了したい**
右クリック → **終了する**。猫が起きていた場合はスリープ防止も一緒にオフになります。猫を寝かせるだけならプログラムは残るので、次にすぐ起こせます。

**スリープ防止が効いているか確認したい**
猫が起きていれば効いています。Windows の設定 → システム → 電源にある画面オフの時間を過ぎても画面が点いていれば確実です。

**別の PC でも同じ位置・サイズで使いたい**
設定はユーザーアカウント内に保存され、アップデートしても維持されます。新しい PC では猫を一度動かしてサイズを選べば、それが記憶されます。

## 設定

設定画面はなく、右クリックメニューで変更します。変更するとすぐ保存されます。

| 項目 | 既定値 |
|---|---|
| 表示サイズ | 200% |
| 猫の位置 | メインモニターの右下(タスクバーの上) |
| 起動時に実行 | オフ |
| スリープ防止の状態 | 保存しない — 常に眠った状態で開始 |

表示言語は Windows の表示言語に従います(韓国語・英語・日本語・中国語・ロシア語・イタリア語・フランス語、それ以外は英語)。

## 動作環境

- Windows 10 または Windows 11(32 ビット・64 ビットの両方)
- 管理者権限は不要です。追加のランタイムも不要です。
- インターネット接続は新バージョンの案内確認にのみ使います。オフラインでも動作します。

## アップデート

StayOn は自動的にはアップデート**しません**。起動時に新バージョンの有無を確認して案内画面を表示し、**[はい]** を押すとダウンロードページが開いてプログラムが終了します。新バージョンは内部検証の後に手動で配布され、[StayOn ページ](https://v2.kilho.net/stayon)で告知されます。[アップデートポリシー](https://en.kilho.net/archives/notice/2940)をご覧ください。
