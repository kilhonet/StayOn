# 끄지마

## 개요

발표 자료를 띄워 두거나, 긴 다운로드를 걸어 두거나, 문서를 읽고 있는데 몇 분 만에 화면이 꺼지고 컴퓨터가 잠들어 버린 적이 있을 겁니다. 회사 PC 는 전원 설정을 바꿀 수 없는 경우도 많습니다.

끄지마는 바탕화면 구석에 픽셀 아트 고양이 한 마리를 띄웁니다. **자고 있는 고양이를 클릭하면 깨어나고**, 고양이가 깨어 있는 동안에는 화면이 꺼지지도, 컴퓨터가 절전 모드로 들어가지도 않습니다. 다시 클릭하면 고양이는 잠들고 모든 것이 평소대로 돌아갑니다.

Windows 의 전원·절전 설정은 전혀 건드리지 않습니다. 프로그램이 실행 중인 동안만 효과가 있고, 끄거나 재부팅하면 아무 흔적도 남지 않습니다. 실행 파일 하나, 100 KB 도 안 되는 크기입니다.

## 주요 기능

- **클릭 한 번** — 고양이를 클릭하면 절전 방지 켜기/끄기. 우클릭 메뉴로도 됩니다.
- **화면 꺼짐 · 절전 · 잠금 방지** — 화면 보호기, 화면 끄기, 절전 모드, 자동 잠금이 동작하지 않습니다. Teams 같은 메신저의 "자리 비움" 표시도 막습니다.
- **Windows 설정 무변경** — 전원 옵션이나 그룹 정책을 바꾸지 않습니다. 관리자 권한도 필요 없습니다.
- **어디든 두는 고양이** — 끌어서 원하는 자리에 놓으면 위치가 기억됩니다. 화면 밖으로는 나가지 않습니다.
- **화면크기 100 % · 200 % · 400 %** — 모니터 크기에 맞춰 고양이 크기를 고릅니다. 고해상도(HiDPI) 화면에서도 선명합니다.
- **부팅시 실행** — Windows 시작과 함께 고양이가 나타납니다(설치판).
- **가볍고 단순** — C 로 새로 만들어 실행 파일 83 KB, 설치·설정 창 없음. 항상 맨 위에 떠 있지만 작업 표시줄이나 Alt+Tab 목록에는 나타나지 않습니다.
- **7개 언어** — 한국어 · 영어 · 일본어 · 중국어 · 러시아어 · 이탈리아어 · 프랑스어. Windows 표시 언어를 따릅니다.

## 사용법

### 처음 사용하기

1. 끄지마를 실행합니다. 화면 오른쪽 아래(작업 표시줄 위)에 **자고 있는 고양이**가 나타납니다.
2. 고양이를 **클릭**합니다. 고양이가 기지개를 켜며 깨어나고, 이때부터 화면이 꺼지거나 컴퓨터가 잠들지 않습니다.
3. 할 일을 합니다. 고양이는 깨어 있는 동안 화면 위에 그대로 있습니다.
4. 끝나면 고양이를 **다시 클릭**합니다. 고양이가 다시 잠들고 절전 설정이 평소대로 돌아갑니다.

프로그램을 켜면 고양이는 **항상 자는 상태**로 시작합니다. 어제 깨워 둔 채 껐더라도 다음 실행에서 저절로 켜지지는 않습니다 — 화면을 켜 둘 생각이 없는데 켜져 있는 일이 없도록 한 것입니다.

### 화면 구성

창이나 설정 화면은 없고, 고양이와 **우클릭 메뉴**가 전부입니다.

| 메뉴 | 하는 일 |
|---|---|
| **실행하기** / **실행중지** | 절전 방지 켜기/끄기 — 고양이를 클릭하는 것과 같습니다 |
| **화면크기** › 100% · 200% · 400% | 고양이 크기. 기본은 200% |
| **부팅시 실행** (체크) | Windows 시작 시 자동 실행 (설치판) |
| **만든이 오길호** | 홈페이지 열기 |
| **종료하기** | 프로그램 끝내기 — 절전 방지도 함께 꺼집니다 |

- **잠든 고양이** = 절전 방지 꺼짐, **깨어 있는 고양이** = 절전 방지 켜짐. 따로 상태 표시가 없어도 고양이만 보면 압니다.
- **끌어서 이동** — 고양이를 누른 채 끌면 옮겨집니다. 살짝 움직인 것은 클릭으로 봅니다.

### 이럴 때 이렇게

**발표·회의 중에 화면이 꺼지지 않게**
발표 자료를 띄우기 전에 고양이를 한 번 클릭해 깨워 두세요. 발표가 끝나면 다시 클릭해 재웁니다. 프로젝터나 회의실 PC 에서도 전원 설정을 만질 필요가 없습니다.

**긴 다운로드나 작업을 걸어 두고 자리를 비울 때**
고양이를 깨워 두면 자리를 비워도 컴퓨터가 잠들지 않아 작업이 계속됩니다. 돌아와서 고양이를 재우면 됩니다. 컴퓨터 자체를 끄는 것과는 무관하므로, 작업이 끝난 뒤 직접 종료하면 됩니다.

**Teams · Slack 이 자꾸 "자리 비움" 으로 바뀔 때**
문서를 읽거나 회의를 듣기만 해서 마우스를 안 움직이면 메신저가 자리 비움으로 표시합니다. 고양이를 깨워 두면 자리 비움으로 넘어가지 않습니다.

**회사 PC 라 전원 설정을 바꿀 수 없을 때**
끄지마는 Windows 설정을 바꾸지 않고 관리자 권한도 쓰지 않습니다. 그룹 정책으로 화면 꺼짐 시간이 고정된 PC 에서도 고양이가 깨어 있는 동안은 화면이 유지됩니다.

**고양이가 작업에 방해될 때**
- 원하는 자리로 **끌어다** 놓으세요. 위치는 기억됩니다.
- 우클릭 → **화면크기** → **100%** 로 줄이면 눈에 거의 띄지 않습니다.
- 고양이는 화면 밖으로 밀어낼 수 없습니다. 모니터 가장자리에 붙는 데까지만 갑니다.

**고양이가 너무 작을 때 (4K 모니터 등)**
우클릭 → **화면크기** → **400%**. Windows 배율 설정에 다시 곱해지므로 어떤 해상도에서도 선명합니다.

**컴퓨터를 켤 때마다 고양이가 나오게**
설치판에서 우클릭 → **부팅시 실행**을 체크합니다. 다음 부팅부터 로그온하면 고양이가 자는 상태로 나타납니다. 무설치판에서는 이 항목이 잠겨 있으니 설치판을 쓰세요.

**고양이가 안 보일 때**
- 이미 실행 중이면 두 번째로 실행해도 아무 일도 일어나지 않습니다(한 번에 하나만 뜹니다). 화면 구석과 다른 모니터를 확인하세요.
- 모니터 구성이 바뀌어 저장된 위치가 화면 밖이 되면 자동으로 기본 위치(주 모니터 오른쪽 아래)로 돌아옵니다.

**끄지마를 완전히 끝내기**
우클릭 → **종료하기**. 고양이가 깨어 있었다면 절전 방지도 함께 꺼집니다. 그냥 고양이를 재우기만 하면 프로그램은 남아 있어 다음에 바로 다시 깨울 수 있습니다.

**절전 방지가 되고 있는지 확인하고 싶을 때**
고양이가 깨어 있으면 됩니다. Windows 설정 → 시스템 → 전원 의 화면 끄기 시간이 지나도 화면이 켜져 있는지 보면 확실합니다.

**다른 PC 에서도 같은 위치·크기로 쓰고 싶을 때**
설정은 사용자 계정 안에 저장되며 업데이트해도 유지됩니다. 새 PC 에서는 고양이를 한 번 옮기고 크기를 고르면 그대로 기억됩니다.

## 설정

설정 창은 없고 우클릭 메뉴에서 바꿉니다. 바꾸는 즉시 저장됩니다.

| 항목 | 기본값 |
|---|---|
| 화면크기 | 200% |
| 고양이 위치 | 주 모니터 오른쪽 아래 (작업 표시줄 위) |
| 부팅시 실행 | 꺼짐 |
| 절전 방지 상태 | 저장하지 않음 — 항상 자는 상태로 시작 |

화면 언어는 Windows 표시 언어를 따릅니다(한국어 · 영어 · 일본어 · 중국어 · 러시아어 · 이탈리아어 · 프랑스어, 그 외는 영어).

## 요구 사항

- Windows 10 또는 Windows 11 (32비트 · 64비트 모두)
- 관리자 권한이 필요 없습니다. 별도 런타임도 필요 없습니다.
- 인터넷 연결은 새 버전 안내 확인에만 씁니다. 오프라인에서도 동작합니다.
